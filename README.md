# RR ALIADOS // GROWTH PARTNER OS

Sistema de inteligencia conversacional y análisis estricto de reuniones. Captura audio en tiempo real, procesa la transcripción mediante modelos IA locales (Whisper + Ollama) y genera reportes ejecutivos en Word (.docx).

## Prerequisitos del Equipo

Antes del primer arranque, asegúrate de tener instalado en el sistema:

1. **Python 3.11+** y **`uv`** (`pip install uv`)
2. **Node.js 18+** & **npm**
3. **Ollama** con el modelo predeterminado descargado (`ollama run phi4-mini`)
4. **Broker Mosquitto** instalado en el sistema.
